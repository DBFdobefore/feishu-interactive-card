# 飞书交互式卡片 2.0 输出规范

让 AI Agent 在飞书中以漂亮的可折叠卡片发送长回复，而不是大段纯文本。

## 这是什么

一份给 AI Agent 的行为规范（Skill），定义了何时以及如何用飞书交互式卡片 2.0 格式发送回复：折叠面板、颜色轮换、完整 JSON 模板、常见坑解决方案。

## 快速使用

将 `SKILL.md` 中的「方式一」段落复制到你的 Agent 的 `SOUL.md` 即可。详细说明见 SKILL.md。

## 适用场景

- 多板块内容（产品介绍、参数对比、选购建议）
- 版本更新说明
- 需要折叠面板组织的大量信息
